# Notice

This project is an unofficial digital adaptation of **Regicide**, a cooperative
card game designed by **Paul Abrahams** and published by
**[Badgers from Mars](https://www.badgersfrommars.com/regicide)**.

The original game's design and rulebook are released under the
[Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

## Attribution

- Original design © Paul Abrahams / Badgers from Mars
- Distributed under CC BY 4.0

## Modifications

This implementation:

- Adapts the rules to a solo digital format (computer-managed deck, automated
  power resolution, on-screen forecasts, etc.).
- Uses original UI copy and tooltips written for this app — no rulebook text is
  reproduced verbatim.
- Uses no art or visual assets from the published game; cards are rendered with
  Unicode suit glyphs and standard web typography.

If you enjoy this adaptation, please consider buying a physical copy of Regicide
from Badgers from Mars to support the original creators.
